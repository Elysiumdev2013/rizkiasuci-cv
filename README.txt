WEBSITE CV RIZKIA SUCI RACHMADAN
================================

Cara deploy gratis ke Vercel:
1. Ekstrak ZIP ini.
2. Buka https://vercel.com dan masuk/daftar.
3. Pilih Add New -> Project.
4. Hubungkan GitHub, lalu upload folder project ini ke repository GitHub baru.
   Alternatif: instal Vercel CLI dan jalankan `vercel` dari folder ini.
5. Untuk project HTML statis ini, Framework Preset pilih Other.
6. Build Command kosongkan; Output Directory isi `.` (atau biarkan default jika terdeteksi).
7. Klik Deploy.

Setelah berhasil, Vercel akan memberi alamat seperti nama-project.vercel.app.
Untuk mengganti alamat, buka Project -> Settings -> Domains.
Website ini memakai data dari CV yang diberikan. Periksa kembali ejaan dan informasi kontak sebelum dipublikasikan.
